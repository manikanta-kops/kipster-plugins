# Kipster Plugins planner additions

Read the plan and the testing guide. Challenge assumptions against the actual code and the services' published behavior. Each plan names the test level that proves every acceptance criterion: fixture service, live probe or owner-run real account. Class A plugins are configuration on one generic remote MCP implementation; plan per-service code only for the special cases the plan names. Keep the server standalone, and keep the control API and MCP surface additive. Listeners are out of scope until the owner schedules them.
